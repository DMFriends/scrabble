# Scrabble

Desktop **Scrabble-style word game** written in **Java** with **JavaFX**. 
Uses the official [Tournament Word List](https://norvig.com/ngrams/TWL06.txt) dictionary and builds the tile bag from **`letters.csv`** (letter, count per tile type, point value).

## Requirements

- [**JDK 26**](https://www.oracle.com/java/technologies/downloads/#jdk26-windows)


## Running

1. Clone this repository.
2. Download the `.exe` file from the [latest release](https://github.com/DMFriends/scrabble/releases/latest) and save it in the root directory of the project.
3. Run the `.exe`.
